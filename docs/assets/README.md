# Superteam Academy — brand asset pack

Everything here is derived from the official Superteam Academy logo vector and the
shipping product's design tokens. Read `../readme.md` for the full system, or
`../brand-guide/Superteam Academy Brand Guide.html` for the printable guide.

## logo/ — master vectors

**Colourways:** ink `#19231B` on light · white on dark · black for one-colour print ·
Superteam yellow `#FFD23F` and emerald `#2ECC8E` on coloured fields ·
Solana gradient for credential/NFT contexts only.

## exports/ — ready-to-hand-off files

- `icons/` — favicons 16–512, `maskable-forest-512` (PWA), `appletouch-*-180`, app icons 1024, transparent marks 1024.
- `print/` — 300dpi-class rasters: lockup 3000px, wordmark 2400px, stacked 2000px, mark 1500px.
- `social/` — OG card 1200×630 (navy + forest), banner 1500×500, square post 1080×1080.

## decorative/ + backgrounds/

Tiling dot grids (22px light/dark, 18px certificate), scanlines, gradient hairline,
Solana gradient bar, ambient glow blobs, octagon medal motif and blank medal;
full-bleed dot-grid and hero-glow fields (navy + cream, 1920×1080), a panel glow strip,
and the Solana credential field (1200×630).

## imagery/ + reference/

`imagery/course-cover-default.png` is the product's course cover placeholder.
`reference/` holds real product screenshots (dashboard, challenge, certificate) — for
reference only, not for external publication.

## Quick rules

1. The **Academy lockup** leads everywhere; Superteam Brasil is a "Powered by" credit.
2. Minimum sizes: lockup 110px wide · stacked 80px · mark 16px. Below 110px, use the mark.
3. Clearspace: one cap-height of the "s" on all four sides.
4. Never recolour, add effects, stretch, or rebuild the wordmark.
5. The Solana gradient is for credentials and NFTs — never as a brand colour.
